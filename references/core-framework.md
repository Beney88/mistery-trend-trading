# 核心框架

## 1. 交易哲学

原文反复强调：市场不确定性永恒，没有固定战法可以跨环境通吃；战法是工具，交易是认知，执行靠人性。稳定来自认知边界、纪律、等待、适应性、抗挫力和执行力。交易不是预测每一次涨跌，而是在可接受风险内重复正期望的决策。

核心排序：

1. 先判断趋势和市场环境；
2. 再选择与环境匹配的风格和标的；
3. 再用结构、量价和技术指标找位置；
4. 最后用仓位、止损和持仓纪律控制结果。

## 2. 大势与三周期

- 月线：判断长期周期、估值和大级别方向。
- 周线：确认中期上升/下降趋势、通道和关键支撑。
- 日线：寻找箱体、旗形、W 底、趋势回踩、突破等结构。
- 60 分钟及更小：只在大中周期成立时择时，例如缩量回踩企稳、放量突破、底背离或均线重新转强。

“三周期共振”的流程：筛选月/周向上的板块和标的 → 在日线等待整理结束或回调支撑 → 用小周期确认进场。大周期定方向，中周期选结构，小周期抓节奏；若周期冲突，降低仓位或等待。

## 3. 趋势票与情绪票

### 趋势票

逻辑通常来自行业景气、业绩改善、政策方向、竞争优势或持续资金流入。特征是均线/通道较清晰，涨一段、调一段，顶部较慢。适合中线、波段和有本职工作的投资者。

优先方法：基本面筛选 → 放量突破或趋势回调 → 缩量回踩关键均线/前高 → 放量恢复时介入或加仓 → 趋势未破坏则持有 → 以 5/10/20/60 日线、前低或 ATR 做移动止盈。

### 情绪票

逻辑来自题材、消息、资金接力和情绪共振，节奏快、涨跌急、持续性弱。核心不是估值，而是概率、速度和执行力。只在情绪回暖、题材启动和核心龙头确认时参与；高潮减仓，分化/退潮离场，不抄底接飞刀。

情绪周期可分为：冰点/潜伏 → 启动 → 加速 → 高潮 → 分化 → 冰点。口诀：冰点观察，启动试水，加速参与，高潮减仓，退潮空仓。

## 4. 选股与持股

回调后先判断下跌性质：

- 系统性回调：市场整体下跌，优质公司可能被错杀；
- 结构性回调：行业或个股短期扰动，长期逻辑未变才考虑布局；
- 根本性回调：业绩、竞争格局或行业逻辑恶化，不把下跌当机会。

筛选顺序：行业/板块趋势 → 龙头与竞争优势 → 盈利、负债、现金流 → 估值安全边际 → 资金与技术止跌。优先“核心资产 + 龙头股”，不要因为价格低就把弱势股当价值股。

趋势持有的基本规则：趋势不破不下车；缩量回调不等于见顶；跌破关键支撑、放量破位、均线系统转弱或基本面失效才退出。强势主升阶段可用 5 日线跟随，波段趋势可用 20/60 日线或结构低点防守。

## 5. 指数底仓与个股进攻

原文建议把宽基 ETF/指数定投视作基础盘，把个股交易视作轻仓进攻；定投的前提是资产长期向上、期限足够长，并仍需避免高位一次性追涨。具体 ETF、指数和长期预期都必须用最新数据重新核验。
