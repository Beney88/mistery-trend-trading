# 宏观、流动性与产业周期

## 1. 流动性优先级

原文把牛熊差异归结为流动性：政策和货币环境像水源，成交额和量能是市场中可观察的水流。流动性宽松时，趋势和板块轮动的容错率更高；流动性收紧或存量博弈时，追高、重仓和频繁交易的风险上升，宜轻仓、精选和等待。

观察宏观数据时，不孤立解读单项指标：

- CPI：需求与居民生活成本；
- PPI：生产端成本、价格和利润压力；
- 社融：实体融资与信用扩张；
- 出口：外部需求与制造业订单。

把数据方向与政策、指数成交额、行业相对强弱和公司盈利结合，不用一条数据直接预测股价。

## 2. 产业周期

用“萌芽 → 成长 → 成熟 → 衰退”判断行业位置：

- 萌芽：逻辑和政策驱动，路线不确定，轻仓、严止损、等待验证。
- 成长：需求放量、订单和收入增长，优先龙头与技术优势企业，趋势和业绩双确认。
- 成熟：增速放缓、格局稳定，重现金流、分红、估值和防御。
- 衰退：需求下降、产能过剩，通常回避；只有出清、并购或政策拐点出现时才小仓博弈，不能把低估值等同于安全。

验证产业周期的变量：行业利润增速、产能利用率、库存、产品价格、龙头季报、政策和行业景气指数。

## 3. 估值框架

- 价值股：重点看 PB 安全边际、ROE 稳定性、现金流和分红；低 PB 但 ROE 持续下降可能是价值陷阱。
- 成长股：重点看行业空间、收入/利润增长和 ROE 趋势，PE 高低要结合增长兑现，不能只看静态低估值。
- 数学关系：`PE = PB / ROE`。PB 反映市场给的资产溢价，ROE 反映盈利效率，PE 是两者共同结果。

宏观/估值用于筛选方向和风险边界，技术面用于择时；两者冲突时降低仓位，而不是用一个指标强行覆盖另一个。
